# Power BI project

Open `IntelligentDemand.pbip` in Power BI Desktop, then choose Refresh.

- `IntelligentDemand.SemanticModel/`: TMDL star schema and 69 DAX measures (generated by `bi/tmdl.py`).
- `IntelligentDemand.Report/`: PBIR report, five pages, 86 visuals (generated by `bi/report_builder.py`).
- `theme/IntelligentDemandAcademic.json`: report theme.

The data comes from `artifacts/powerbi/data/` (build it with
`.venv\Scripts\python.exe -m intelligent_demand.bi.export`). After moving the project, update the
`DataRoot` parameter. Full guide, KPI definitions and verification evidence:
[docs/PHASE6_POWERBI_DASHBOARD.md](../docs/PHASE6_POWERBI_DASHBOARD.md).

Inventory figures are hypothetical normalised cost units (NCU), not realised savings.
